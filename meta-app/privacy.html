개인정보처리방침

AdOS가 Meta Marketing API 연동 과정에서 어떤 데이터를 왜 처리하는지 설명합니다.

시행일 / Effective: 2026-07-31 운영자 / Controller: AdOS
AdOS는 일반 Facebook 사용자를 대상으로 Facebook Login을 제공하지 않으며, 개인정보를 판매하지 않습니다.

1. 적용 범위 / Scope

본 방침은 운영자가 승인한 비즈니스 광고계정과 페이지를 AdOS에 연결해 Meta 광고를 생성, 동기화 및 분석할 때 적용됩니다. AdOS is an internal advertising operations tool. It does not provide a consumer-facing Facebook Login experience.

2. 처리하는 데이터 / Data We Process

  • Meta Business, 광고계정 및 페이지 식별자
  • 캠페인, 광고세트, 광고, 소재의 이름·식별자·설정·상태
  • 노출, 클릭, 비용 등 집계된 광고 성과 지표
  • 운영자가 입력한 광고 문구, 이미지 URL 및 랜딩 URL
  • 오류 기록, 실행 시각과 같이 보안 및 장애 대응에 필요한 기술 로그

We do not intentionally collect personal profile data, friends lists, private messages, contacts, precise location, or sensitive personal data from Facebook users.

3. 처리 목적 / Purposes

  • 승인된 광고계정의 광고 리소스 생성 및 상태 동기화
  • 예산, 입찰 및 집행 상태의 운영 제어
  • 광고 성과 보고서 작성과 장애 진단
  • 중복 생성 및 오집행 방지를 위한 리소스 식별자 보관

4. 처리 근거와 데이터 출처 / Basis and Sources

데이터는 계정 운영자의 명시적 지시 및 권한 부여에 따라 처리됩니다. 데이터는 운영자의 설정과 Meta Marketing API에서 제공되는 승인된 비즈니스 자산 정보에서 수집됩니다.

5. 공유 및 처리 위탁 / Sharing and Service Providers

AdOS는 개인정보를 판매하지 않습니다. 자동화 실행, 보안 비밀 관리, 데이터 저장, 소재 생성 및 정적 파일 제공에 필요한 인프라 제공자에게 업무 수행에 필요한 최소 범위의 데이터가 처리될 수 있습니다. 법령상 요구되거나 권리 보호에 필요한 경우를 제외하고 광고 목적의 제3자에게 데이터를 제공하지 않습니다.

6. 보유 기간 / Retention

광고 리소스 식별자와 운영 기록은 연동 및 광고 운영에 필요한 동안 보관합니다. 계정 연결 해제 또는 유효한 삭제 요청이 접수되면 법적 보존 의무, 보안 사고 대응 및 분쟁 해결에 필요한 정보를 제외하고 합리적인 기간 내 삭제하거나 비식별화합니다.

7. 보안 / Security

접근 토큰은 공개 문서나 소스 코드에 저장하지 않고 제한된 비밀 관리 환경에서 처리합니다. 접근 통제, 최소 권한, 전송 암호화 및 실행 기록을 사용해 무단 접근과 오용 위험을 줄입니다.

8. 이용자의 권리 / Your Rights

관련 법률이 허용하는 범위에서 본인 데이터의 열람, 정정, 삭제, 처리 제한 또는 반대를 요청할 수 있습니다. 요청 방법은 사용자 데이터 삭제 안내를 확인하세요.

9. 아동 / Children

AdOS는 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

10. 방침 변경 / Changes

데이터 처리 방식이 변경되면 이 페이지의 내용과 시행일을 갱신합니다. 중요한 변경은 합리적인 방법으로 운영자에게 알립니다.
